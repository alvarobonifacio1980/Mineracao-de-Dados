## Fonte pública

A base utilizada no trabalho é derivada dos dados públicos do **Inside Airbnb — New Zealand**.

Fonte oficial:
https://insideairbnb.com/get-the-data/

O notebook acadêmico original utilizou o arquivo `4_New-Zealand.csv`, com um snapshot específico já tratado para a atividade. Como o arquivo exato não está mais disponível no acervo conectado desta conversa, o repositório mantém a fonte oficial e um script de aquisição para reconstrução a partir do snapshot público.

> Para reproduzir **numericamente** os resultados originais, use o mesmo snapshot da disciplina. Snapshots mais recentes podem alterar quantidade de registros e estatísticas.

## Arquivo alternativo fornecido para reprodução

O arquivo `10_New-Zealand.csv` (23.941 registros e 17 colunas) foi fornecido pelo autor para utilização como **base alternativa**. O notebook reconhece o arquivo quando colocado em `01_pre_processamento_eda/data/10_New-Zealand.csv`, preservando a prioridade da base original `4_New-Zealand.csv` (25.006 registros). O arquivo alternativo **não está incluído neste commit**; disponibilizá-lo separadamente não significa que seus resultados correspondam aos originalmente documentados. Os tratamentos podem precisar de revisão diante de diferenças entre snapshots.
